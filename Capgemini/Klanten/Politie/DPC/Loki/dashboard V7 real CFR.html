Hoe wordt de CFR berekend (DORA-Standaard)?
De tool berekent het percentage Releases dat heeft gefaald. Een release telt als 'Gefaald' als:
1. Het een Hotfix is (0 features, alleen bugs).
2. Er ná livegang minimaal één kritieke bug (High, Highest, Major, Critical, P1, P2) in de release is gemeld. Cosmetische post-release bugs laten een release niet falen.

Formule: (Aantal Gefaalde Releases / Totaal Aantal Releases) * 100
