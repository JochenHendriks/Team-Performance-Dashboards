Hoe wordt de CFR berekend (DORA-Standaard)?
De tool berekent het percentage Releases dat heeft gefaald. Een release faalt als:
1. Het een Hotfix is (een release met 0 features en minimaal één aangevinkte bug).
2. De release de Oorzaak is van een kritieke bug. Dit bepalen we via een trechter:
    a) Gouden Standaard: De release is expliciet gekoppeld in het veld Affects Version van de bug.
    b) Fallback: Als Affects Version leeg is, faalt de release als de bug óp of ná de releasedatum is gemeld (Post-release).

Belangrijk: Een bug laat een release alléén falen als de prioriteit ervan hieronder is aangevinkt! Cosmetische bugs (zoals Minor) kun je dus veilig negeren.

Formule: (Aantal Gefaalde Releases / Totaal Aantal Releases) * 100
