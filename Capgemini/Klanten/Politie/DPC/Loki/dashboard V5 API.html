Geconstrueerde JQL voor issues:

Hoe wordt de CFR berekend?
De tool haalt eerste de officiële releasedatums op via de projectinstellingen van Jira.
1. Pre-release Bugs: Bugs die vóór deze officiële datum zijn aangemaakt, zijn tijdens de bouwfase afgevangen en tellen niet mee voor de CFR.
2. Post-release Bugs: Bugs die óp of ná de officiële releasedatum zijn aangemaakt, gelden als productie-incidenten. Alleen deze beïnvloeden de CFR.

Formule: (Aantal Post-release bugs / Aantal Changes) * 100 = Totale CFR %
